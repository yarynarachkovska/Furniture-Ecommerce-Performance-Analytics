# Furniture E-Commerce Performance Analytics

## Overview

This project presents an end-to-end analysis of furniture e-commerce sales data using SQL, Python, and Tableau.

The workflow covers data extraction from BigQuery, data preparation, exploratory analysis, statistical testing, and interactive dashboard development. The objective is to uncover business insights related to revenue performance, customer behavior, traffic channels, product categories, devices, and geographic markets.

The project demonstrates a complete analytics workflow, from raw data querying to stakeholder-focused data visualization.

## Project Description

The analysis focuses on:

* Extracting and transforming data using SQL in BigQuery
* Preparing and cleaning datasets for analysis
* Exploring revenue and customer behavior patterns
* Performing statistical analysis and hypothesis testing
* Identifying key sales drivers and performance trends
* Building an interactive Tableau dashboard for business monitoring

## Dataset

The dataset contains furniture e-commerce transactions and user session information, including:

* Orders and revenue
* Product categories and products
* Customer account information
* Traffic channels and acquisition sources
* Device types and browsers
* Geographic data (countries and continents)
* Session-level behavioral metrics

## Key Analysis Components

### Exploratory Data Analysis

* Revenue trends over time
* Order volume analysis
* Product category performance
* Country and continent comparisons
* Device and traffic channel analysis

### Statistical Analysis

* Comparison of sales between registered and unregistered users
* Analysis of session distributions across traffic channels
* Organic traffic share comparison between regions
* Correlation analysis between sessions, sales, and business metrics
* Hypothesis testing using appropriate statistical methods

### Business Intelligence Dashboard

The Tableau dashboard provides:

* Revenue and Average Order Value trends
* Revenue breakdown by device and traffic channel
* Top-performing countries and product categories
* Interactive filtering by date, country, device, and category
* Executive-level KPI monitoring
