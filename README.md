# Furniture E-Commerce Performance Analytics

## Overview

This project analyzes furniture e-commerce sales data using SQL (BigQuery), Python, and Tableau. The workflow includes data extraction, cleaning, exploratory analysis, statistical evaluation, and interactive dashboard development to uncover key business insights and performance drivers.

## Project Goals

* Analyze revenue performance and sales dynamics over time
* Evaluate customer purchasing behavior and order value trends
* Identify top-performing product categories and countries
* Compare revenue across traffic channels and devices
* Build an interactive business dashboard for decision-making

## Tools & Technologies

* SQL (BigQuery)
* Python
* Pandas
* NumPy
* SciPy
* Matplotlib
* Seaborn
* Tableau Public
* Google Colab

## Key Analysis Areas

* Revenue and sales performance trends
* Average Order Value (AOV) analysis
* Product category performance
* Geographic sales distribution
* Traffic channel effectiveness
* Device-based revenue comparison
* Statistical analysis of customer behavior metrics

## Dashboard

The Tableau dashboard provides an interactive overview of business performance through revenue trends, order value analysis, product and country rankings, channel performance, and customer purchasing patterns.

Interactive filters allow users to explore the data by date, country, device type, and product category.

## Business Value

The project helps identify the most profitable products, channels, customer segments, and markets, supporting data-driven decisions in marketing, sales optimization, and business strategy.
